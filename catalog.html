Add a variable / column

A variable should be a positive, ratio-scale numeric quantity in one consistent unit (not a temperature or date). Items can leave it blank. Templates support {aName}, {aPlural}, {bName}, {bPlural}, {unit}, and {property}.

Local edits vs. published game

Saving stores this catalog only in this browser. To share it with every player, export the JSON and replace data/items.json in the repository, then commit and deploy the updated site. No account, server, or external API is used by this editor.
